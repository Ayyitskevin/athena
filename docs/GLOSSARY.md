# Athena glossary

Use these distinctions when reading work or proposing changes; the linked owners
define the full contracts. The [decision index](decisions/README.md) records why
selected rules were accepted, separately from proposals still awaiting a decision.

| Term | Meaning and boundary | Owner / implementation |
|---|---|---|
| **Account** | A stored user identity for a person or agent, constrained by roles and token scopes. It is not a running process or a seat name. | [RUNTIME_RECIPE.md](RUNTIME_RECIPE.md), [users.py](../src/athena/core/users.py) |
| **Seat** | A configured agent runtime or client using an account's credentials. A different process or label alone does not create a separate authenticated identity. | [AGENT_BOOT.md](AGENT_BOOT.md), [identity.py](../src/athena/core/identity.py) |
| **Claim** | The deliberate action that acquires or renews an issue lease under current eligibility and preconditions. It is not assignment, issue completion, or evidence that work ran. | [ACTIVE_WORK.md](ACTIVE_WORK.md), [lease_commands.py](../src/athena/aegis/lease_commands.py) |
| **Lease** | The issue's holder, expiry, and possession-generation record; active means its expiry is still in the future. It is not process health or an operating-system file lock. | [ACTIVE_WORK.md](ACTIVE_WORK.md), [leases.py](../src/athena/aegis/leases.py) |
| **Possession generation** | An opaque value identifying one lease acquisition, preserved on renewal and replaced on a new acquisition. It is not a run id or permanent account identity. | [ACTIVE_WORK.md](ACTIVE_WORK.md), [leases.py](../src/athena/aegis/leases.py) |
| **Run** | A projection of activity events sharing run metadata. It is not a supervised process, mutable run authority, or a lease. | [RUNS.md](RUNS.md), [activity.py](../src/athena/core/activity.py) |
| **Run report / check-in** | An authenticated agent's cooperative heartbeat, with server-owned observation times. It is not proof of process health, work execution, or lease renewal. | [RUNS.md](RUNS.md), [agent_run_commands.py](../src/athena/core/agent_run_commands.py) |
| **Activity event** | A stored, attributed audit record of an application action or explicitly imported history. It is not independent verification of the actor's statements or external work. | [RUNS.md](RUNS.md), [activity.py](../src/athena/core/activity.py) |
| **Verification** | An actual check of a named subject and scope, retaining outcomes and limits. Recording an event or linking an evidence reference does not perform that check. | [EVIDENCE_MANIFEST.md](EVIDENCE_MANIFEST.md), [activity_chain.py](../src/athena/core/activity_chain.py) |
| **Hash chain** | SHA-256 links between post-adoption activity rows let a verifier check recorded history within its declared range. They do not sign authorship, prove external work, cover pre-adoption rows, or defeat rewriting both tables or truncating an unwitnessed tail. | [TRAIL_INTEGRITY.md](TRAIL_INTEGRITY.md), [activity_chain.py](../src/athena/core/activity_chain.py) |
| **Approval** | A single-use authorization of one requester's action kind and target, consumed with a successful ordinary retry. It is not approval of exact payload bytes, a stored action to replay, or permission to bypass current checks. | [APPROVALS.md](APPROVALS.md), [approvals.py](../src/athena/core/approvals.py) |
| **Reported completion** | An optional lease-release report whose conditions say `met` (reported satisfied), `not_met` (reported unsatisfied), `not_assessed` (not evaluated), or `inconclusive` (evaluated without a settled answer). These are actor reports, not verdicts, issue-status changes, approvals, or proof that evidence references were executed. | [CLOSEOUT_RECIPE.md](CLOSEOUT_RECIPE.md), [lease_commands.py](../src/athena/aegis/lease_commands.py) |
| **Recovery bundle** | One database snapshot, its matching attachment blobs, and a manifest binding their bytes. Creation preserves evidence even with a broken activity chain; it is not strict verification, encryption, or permission to restore. | [OPERATIONS.md](OPERATIONS.md), [recovery.py](../src/athena/core/recovery.py) |
| **Portability export** | A selective JSON package for one project or space, including related records and attachment metadata. It is not a whole-database backup and excludes raw blobs, credentials, and operational claim handoffs. | [OPERATIONS.md](OPERATIONS.md), [portability.py](../src/athena/core/portability.py) |
| **Database backup** | A SQLite snapshot made through the online backup API. By itself it is not a matched attachment backup or a copy of service configuration. | [OPERATIONS.md](OPERATIONS.md), [ops.py](../src/athena/ops.py) |
| **Quick gate profile** | Explicit `--profile quick` runs the fast checks and labels success partial. It is not full-suite, product, container, or advisory-audit evidence. | [CONTRIBUTING.md](../CONTRIBUTING.md), [gate.py](../scripts/gate.py) |
| **Product gate profile** | The default gate adds dependency validation, types, and full-suite coverage to the quick checks. Its local pass is not evidence that CI's container or audit jobs passed. | [CONTRIBUTING.md](../CONTRIBUTING.md), [gate.py](../scripts/gate.py) |
| **Recommendation / decision** | A recommendation proposes a choice; an accepted decision has a cited accepting source and recorded status. Neither a proposal nor a decision record's mere existence grants permission to execute an action. | [DECISIONS_PENDING.md](DECISIONS_PENDING.md), [decision index](decisions/README.md) |
