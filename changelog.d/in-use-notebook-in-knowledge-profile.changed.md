- **The knowledge profile opens a notebook (G8).** The `seat+knowledge` MCP
  profile now carries `open_my_notebook` (40 tools, was 39): a seat that can
  edit pages can open its own notebook, which only the `full` profile could
  do before. A notebook longer than the response budget is cut in the tool's
  answer, and the answer names the `get_page` call that reads on.
