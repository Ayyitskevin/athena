- **Argument shapes an agent can read, and refusals that show them (AD9, D31).** `complete_claim`'s `results` and `evidence` and `yield_claim`'s `evidence` publish typed item schemas on MCP and in the OpenAPI document. An `invalid_arguments` refusal lists each bad argument by path under `violations`, shows an example of its shape under `examples` and names the same tool in `next`. Completion evidence gains the kind `command` (`{kind, command, outcome, scope}`, credential-scanned), and `yield_claim` evidence takes these objects beside plain strings, stored as one line each. The MCP listing writes a nullable plain type as `type: [X, "null"]`.
