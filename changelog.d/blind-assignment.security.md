- **Assignment and delegation refuse an account that cannot see the issue.**
  Assigning, delegating or adding a contributor used to accept an account with no
  access to the issue's project and answer with its name, which let a member learn
  that a private-project account existed. The writes now refuse it with exactly the
  answer an unknown id gets, so the eligible-accounts read and every write that
  takes an account are one rule. Put the account in the project first.
