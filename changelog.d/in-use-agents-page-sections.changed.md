- **One agent, one section, and an action returns to it (U10).** On the
  agents page each agent is a disclosure with its own address
  (`#agent-<id>`), shut until opened, so the page lists agents instead of
  showing every agent's whole detail. An action made on an agent returns to
  that agent's section, opens it, and says there what happened and to whom
  ("Paused Sol: ..."); a worker asked to stop is named with its agent.
