Run controls

Every recorded control request, fleet-wide: what was asked of which run, and what the bound agent said back. "Open" means asked, not yet answered, clock still running. Athena records requests and replies — an acknowledgement proves receipt, a completion is the agent's claim, and expired means the clock ran out, never that anything stopped.
