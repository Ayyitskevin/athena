# Athena glossary

Use these distinctions when reading work or proposing changes; the linked owners
define the full contracts. The [decision index](decisions/README.md) records why
selected rules were accepted, separately from proposals still awaiting a decision.

Two tables. The contract terms are the boundaries a change must not blur. The
words in tool names are every word an MCP tool name uses, apart from a short
list of plain verbs and connectives (`get`, `list`, `set`, `my`, `for`, ...):
[`tests/test_glossary_tool_words.py`](../tests/test_glossary_tool_words.py)
holds that each has a row here and that the row says what the word is not the
same as. A row names its words in bold in the Term column; a plural tool word
is covered by its singular. `athena-mcp` serves this file as the resource
`athena://docs/glossary`.

## Contract terms

| Term | Meaning | Not the same as | Owner / implementation |
|---|---|---|---|
| **Account** / **user** | A stored user identity for a person or agent, constrained by roles and token scopes. | A running process or a seat name. | [RUNTIME_RECIPE.md](RUNTIME_RECIPE.md), [users.py](../src/athena/core/users.py) |
| **Seat** | A configured agent runtime or client using an account's credentials. | A separate authenticated identity: a different process or label alone does not create one. | [AGENT_BOOT.md](AGENT_BOOT.md), [identity.py](../src/athena/core/identity.py) |
| **Claim** | The deliberate action that acquires or renews an issue lease under current eligibility and preconditions. | Assignment, issue completion, or evidence that work ran. | [ACTIVE_WORK.md](ACTIVE_WORK.md), [lease_commands.py](../src/athena/aegis/lease_commands.py) |
| **Lease** | The issue's holder, expiry, and possession-generation record; active means its expiry is still in the future. | Process health or an operating-system file lock. | [ACTIVE_WORK.md](ACTIVE_WORK.md), [leases.py](../src/athena/aegis/leases.py) |
| **Possession generation** | An opaque value identifying one lease acquisition, preserved on renewal and replaced on a new acquisition. | A run id or permanent account identity. | [ACTIVE_WORK.md](ACTIVE_WORK.md), [leases.py](../src/athena/aegis/leases.py) |
| **Run** | A projection of activity events sharing run metadata. | A supervised process, mutable run authority, or a lease. | [RUNS.md](RUNS.md), [activity.py](../src/athena/core/activity.py) |
| **Run report / check-in** | An authenticated agent's cooperative heartbeat, with server-owned observation times. | Proof of process health, work execution, or lease renewal. | [RUNS.md](RUNS.md), [agent_run_commands.py](../src/athena/core/agent_run_commands.py) |
| **Activity event** / **activity** | A stored, attributed audit record of an application action or explicitly imported history. | Independent verification of the actor's statements or external work. | [RUNS.md](RUNS.md), [activity.py](../src/athena/core/activity.py) |
| **Verification** / **verify** | An actual check of a named subject and scope, retaining outcomes and limits. `verify_activity_chain` is one: it rehashes a bounded window of the hash chain. | Recording an event or linking an evidence reference, which does not perform that check. | [EVIDENCE_MANIFEST.md](EVIDENCE_MANIFEST.md), [activity_chain.py](../src/athena/core/activity_chain.py) |
| **Hash chain** / **chain** | SHA-256 links between post-adoption activity rows let a verifier check recorded history within its declared range. | A signature: the links do not sign authorship, prove external work, cover pre-adoption rows, or defeat rewriting both tables or truncating an unwitnessed tail. | [TRAIL_INTEGRITY.md](TRAIL_INTEGRITY.md), [activity_chain.py](../src/athena/core/activity_chain.py) |
| **Approval** | A single-use authorization of one requester's action kind and target, consumed with a successful ordinary retry. | Approval of exact payload bytes, a stored action to replay, or permission to bypass current checks. | [APPROVALS.md](APPROVALS.md), [approvals.py](../src/athena/core/approvals.py) |
| **Reported completion** | An optional lease-release report whose conditions say `met` (reported satisfied), `not_met` (reported unsatisfied), `not_assessed` (not evaluated), or `inconclusive` (evaluated without a settled answer). | A verdict, an issue-status change, an approval, or proof that evidence references were executed: these are actor reports. | [CLOSEOUT_RECIPE.md](CLOSEOUT_RECIPE.md), [lease_commands.py](../src/athena/aegis/lease_commands.py) |
| **Candidate submission** / **candidate** | One immutable declaration of an exact repository revision or artifact digest, bound to a native builder completion. Every submission has a fresh ID; repeating the same identity does not revive an earlier review. | Verification of external bytes, which the declaration does not perform. | [REVIEW_QUEUE_SPEC.md](REVIEW_QUEUE_SPEC.md), [review decision](decisions/2026-11-17-exact-version-reviews.md) |
| **Review request** | An instruction to a named, already eligible reviewer to examine one exact submission on a separate review issue. The active lease shows pickup and a later matching reviewer completion supplies the verdict, which the request row carries as `reported_verdict`. | Any other account's review, which never moves it. | [Request specification](REVIEW_REQUEST_SPEC.md), [D4 record](decisions/2026-11-22-requested-reviewer-verdict.md) |
| **Candidate review** | An immutable link from one native reviewer completion to one exact candidate submission. Reported PASS/HOLD remains that actor's judgment. | Proof of correctness, independence, acceptance or authority, which matching IDs and distinct accounts do not give. | [REVIEW_QUEUE_SPEC.md](REVIEW_QUEUE_SPEC.md), [CLOSEOUT_RECIPE.md](CLOSEOUT_RECIPE.md) |
| **Recovery bundle** | One database snapshot, its matching attachment blobs, and a manifest binding their bytes. Creation preserves evidence even with a broken activity chain. | Strict verification, encryption, or permission to restore. | [OPERATIONS.md](OPERATIONS.md), [recovery.py](../src/athena/core/recovery.py) |
| **Portability export** | A selective JSON package for one project or space, including related records and attachment metadata. | A whole-database backup: it excludes raw blobs, credentials, and operational claim handoffs. | [OPERATIONS.md](OPERATIONS.md), [portability.py](../src/athena/core/portability.py) |
| **Database backup** | A SQLite snapshot made through the online backup API. | By itself, a matched attachment backup or a copy of service configuration. | [OPERATIONS.md](OPERATIONS.md), [ops.py](../src/athena/ops.py) |
| **Quick gate profile** | Explicit `--profile quick` runs the fast checks and labels success partial. | Full-suite, product, container, or advisory-audit evidence. | [CONTRIBUTING.md](../CONTRIBUTING.md), [gate.py](../scripts/gate.py) |
| **Product gate profile** | The default gate adds dependency validation, types, and full-suite coverage to the quick checks. | Evidence that CI's container or audit jobs passed; its local pass is not that. | [CONTRIBUTING.md](../CONTRIBUTING.md), [gate.py](../scripts/gate.py) |
| **Recommendation / decision** | A recommendation proposes a choice; an accepted decision has a cited accepting source and recorded status. | Permission to execute an action, which neither a proposal nor a decision record's mere existence grants. | [DECISIONS_PENDING.md](DECISIONS_PENDING.md), [decision index](decisions/README.md) |

## Words in tool names

| Term | Meaning | Not the same as | Owner / implementation |
|---|---|---|---|
| **Acknowledge** | `acknowledge_run_control` records that you read a run control addressed to your run: a receipt and nothing more. You still decline or complete it once you have acted. | Completing or declining the control; marking a notification read; advancing the desk cursor. | [RUN_CONTROLS.md](RUN_CONTROLS.md) |
| **Action** | In `undo_action`, one activity event, reversed by applying its registered inverse as a new audited event. A budget counts metered writes as actions, and an approval policy gates action kinds (`issue.close`, `dispatch.request`). | An edit to history: undo never changes or deletes the original event. | [UNDO.md](UNDO.md), [undo.py](../src/athena/core/undo.py) |
| **Active** | Of a lease, that its expiry is still in the future at this read: the clock's verdict, not a stored state. `get_fleet_active_work` lists agent-held leases. A sprint is active between `start_sprint` and `complete_sprint`. | A process that is alive or doing work; an open issue. | [ACTIVE_WORK.md](ACTIVE_WORK.md), [leases.py](../src/athena/aegis/leases.py) |
| **Agent** | An account whose `is_agent` flag is set. The flag is a display and audit distinction only: roles and token scopes decide what the account may do. The `*_agent` tools act on such an account. | A seat (the runtime using its credentials), a worker process, or a run. | [users.py](../src/athena/core/users.py) |
| **Answerability** | `agent_answerability`: the admin ledger, per agent, of what was asked of it and how it answered (run controls, kill requests to its workers, approvals its gated actions raised, events an undo reversed), derived at read time. You answer for an issue you are assigned, or delegated to its holder. | A score, or a judgment of why a control expired: only the operator judges that. | [ANSWERABILITY.md](ANSWERABILITY.md) |
| **Archive** / **unarchive** | Soft delete: an archived issue or page is hidden from the default lists (a page also from the tree, navigation and search) but kept with its history, and `unarchive_*` restores it. Undo reverses either. | Deletion; an issue's done status; completing a claim. | [issue_commands.py](../src/athena/aegis/issue_commands.py), [page_commands.py](../src/athena/mentor/page_commands.py) |
| **Assign** | `assign_issue` sets an issue's assignee, its one accountable owner; no assignee unassigns it. | Delegation, which adds an agent contributor while the assignee stays accountable; a claim, which is who holds the work now. | [issue_commands.py](../src/athena/aegis/issue_commands.py) |
| **Attention** / **ranking** | `get_attention_ranking` reads the bounded "Now" queue: rows that need someone (a lapsed lease or a HOLD or BLOCKED report on an issue you answer for, claims, blockers, controls), each citing its source, reason and freshness. It labels a safe next action and never executes one. | The ready queue (what you could claim); issue priority. | [fleet_attention.py](../src/athena/aegis/fleet_attention.py) |
| **Automation** / **rule** / **enabled** / **failure** | An admin-only automation rule runs a configured action on matching issues when an activity verb occurs (an event rule) or on a schedule. `enabled` arms or disarms it without deleting it; `list_automation_failures` lists rules whose actions failed. | A run control, a playbook, or a dispatch to an executor. | [AUTOMATION_SCHEDULES.md](AUTOMATION_SCHEDULES.md), [automation.py](../src/athena/aegis/automation.py) |
| **Brief** | `get_project_brief`: a compact project snapshot for a conductor (summary, active claims, blocker edges, handoffs awaiting resume, latest completion reports). `brief=true` on `get_issue_work_context` is another thing: the same packet cut to the issue, its ETag, dependencies, warnings and work order. | Each other; the full work context a claim or a recovery needs. | [PROJECT_BRIEF_SPEC.md](PROJECT_BRIEF_SPEC.md) |
| **Budget** | An account's durable budget: how many metered writes it may make per fixed window (an hour or a day), and, when a coordination ceiling is set beside it, how many comments, claims and delegations. An account with none is unlimited. | The per-token rate limiter, which lives in memory; a tool's response budget, the characters one answer may take in a seat profile. | [AGENT_BUDGETS.md](AGENT_BUDGETS.md), [budgets.py](../src/athena/core/budgets.py) |
| **Bulk** | `bulk_update_issues` applies one change to many issues, each authorized and validated on its own, and reports per issue: best effort. `mark_notifications_read` is the bulk acknowledgement no seat profile carries. | An all-or-nothing batch; the targeted `mark_notification_read`. | [AGENT_API.md](AGENT_API.md) |
| **Claim-next** / **next** | `claim_next_ready` is atomic pickup: the server takes the first ready issue in pickup order (delegated first, then priority, then oldest) and claims it in one call, and claims nothing while your account holds any active lease. Elsewhere `next` is a field: on a truncated list the arguments that continue it, on a refusal the call that resolves it, under `_truncated` the call that reads the rest. | `claim_issue` on an issue you chose; a recommendation; the desk, which reserves nothing. | [ATOMIC_PICKUP_SPEC.md](ATOMIC_PICKUP_SPEC.md), [ready_claim_commands.py](../src/athena/aegis/ready_claim_commands.py) |
| **Comment** | A reply on an issue's thread, authored by the token's account (`comment_on_issue`), read oldest first a page at a time (`list_issue_comments`) and one at a time whole (`get_issue_comment`). Undo does not reverse one; it is deleted explicitly. | An edit of the issue body; a completion report; a run learning. | [comment_commands.py](../src/athena/aegis/comment_commands.py) |
| **Complete** | Three acts. `complete_claim` releases your lease, with an optional report, and leaves the issue open. `complete_sprint` moves an active sprint to completed. `complete_run_control` answers a run control with what you did. | Closing an issue, which is `update_issue` with a done status; verification of the work. | [CLOSEOUT_RECIPE.md](CLOSEOUT_RECIPE.md), [lease_commands.py](../src/athena/aegis/lease_commands.py) |
| **Context** | The work context: `get_issue_work_context`'s bounded packet of one issue with its supporting docs, dependencies, handoffs, comments and recent activity, read before a claim. | A claim or a lease; `request_fresh_context`, a run control asking an agent to close out with a handoff a fresh session can continue. | [WORK_CONTEXT.md](WORK_CONTEXT.md), [work_context.py](../src/athena/aegis/work_context.py) |
| **Run control** / **control** | An operator's recorded request on a live run (`steer`, `request_cancel`, `request_fresh_context`). Only the agent bound to the run reads and settles it, and an unanswered one reads as expired after its time to live. | A signal to a process: it changes nothing a process does; a kill request, which goes to a worker. | [RUN_CONTROLS.md](RUN_CONTROLS.md), [run_controls.py](../src/athena/core/run_controls.py) |
| **Current** | `current_run` reads the run identity this session stamps on its writes (`run_id`, `parent_run_id`, `fork_from_event_id`). `athena-mcp` mints one at start and `begin_run` switches it. | The run itself (the events that share the id); a lease. | [RUNS.md](RUNS.md), [run_context.py](../src/athena/core/run_context.py) |

| **Decline** | `decline_delegation` removes you from an issue's contributors, so the refusal is visible and an operator can re-route it. `decline_run_control` answers a control with why you will not comply. Both are answers, not errors. | Yielding a claim, which keeps you a contributor; a refused call. | [lease_commands.py](../src/athena/aegis/lease_commands.py), [run_control_commands.py](../src/athena/core/run_control_commands.py) |
| **Delegate** / **delegated** / **delegation** | `delegate_issue` adds an agent to an issue's contributors while the human assignee stays accountable. Delegated issues reach the agent's delegation inbox (`list_my_delegated_work`) and come first in pickup. | Assignment; a claim: delegation reserves nothing and starts no work. | [delegations.py](../src/athena/aegis/delegations.py) |
